# Contexto del Proyecto

## Nombre
Wanderlust Labs

## Descripción
Aplicación web creada con React, Next.js y TypeScript para explorar experiencias de viaje alrededor del mundo.

Los usuarios podrán:
- Buscar experiencias
- Filtrar por categoría y destino
- Ver detalles de cada experiencia
- Guardar favoritos

## Tecnologías
- Next.js
- React
- TypeScript
- Tailwind CSS

## Páginas requeridas
- `/` Home
- `/experiences` Explorador
- `/experiences/[id]` Detalle
- `/favorites` Favoritos
- `/profile` Perfil

## Funcionalidades principales

### Búsqueda
La búsqueda debe funcionar por título usando regex case-insensitive.
